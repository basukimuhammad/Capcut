PUBLIC API

Dokumentasi API GenCap

Automasi render video template CapCut. Akses API dengan kunci (unlimited) atau tanpa kunci (limit global 6 req/menit untuk GET).

Dasar URL

Semua endpoint dimulai dari

https://cc.septia.eu.cc/v1/...

Autentikasi — API Key

Kirim header x-api-key (atau query ?api_key=). Dengan key: unlimited. Tanpa key: GET dibatasi 6 request/menit (dipakai bersama semua pengguna), dan generate 2 request/menit global (juga dipakai bareng).

x-api-key: gc_xxxxxxxxxxxxxxxxxxxx
Belum punya key? Hubungi owner — buat di halaman admin /admin.

Endpoint

GET/v1/templates

Daftar semua template yang tersedia (termasuk jumlah foto yang dibutuhkan).

# contoh
curl https://cc.septia.eu.cc/v1/templates \
  -H "x-api-key: gc_..."

GET/v1/templates/:id/info

Info detail template: cover, author, statistik, dan URL video contoh.

GET/v1/tasks/:id

Cek status task render (queued / processing / completed / failed) + tautan video hasil.

POST/v1/tasks

Wajib API key untuk unlimited. Tanpa key tetap boleh, tapi dibatasi 2 generate/menit global (dipakai bareng semua pengguna). Multipart form-data:

curl -X POST https://cc.septia.eu.cc/v1/tasks \
  -H "x-api-key: gc_..." \
  -F template_id=7405909526802615570 \
  -F images=@foto1.jpg \
  -F images=@foto2.jpg \
  -F images=@foto3.jpg

Balasan 201 berisi task.id; gunakan id itu untuk polling GET /v1/tasks/:id.

Limit & Kebijakan

KonteksLimit
GET tanpa API key6 request/menit — dihitung global (dipakai bareng semua user)
GET/POST dengan API keyUnlimited
POST tanpa API key2 generate/menit — dihitung global (dipakai bareng semua user)

Jika limit tercapai server membalas 429 dengan header Retry-After (detik). Response error selalu berbentuk {"error": "..."}.

Contoh JavaScript

// fetch semua template
const res = await fetch('https://cc.septia.eu.cc/v1/templates', {
  headers: { 'x-api-key': 'gc_...' }
});
const data = await res.json();
console.log(data.templates);
